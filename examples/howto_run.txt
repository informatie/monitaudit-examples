Running the example
-------------------
From the project root:

    MONITAUDIT_ENV=dev uv run python examples/main_[xxxxxx].py

Recommended environment:
    dev

Enable JsonSink or DeltaSink when inspecting structured exception fields.

The example intentionally raises a ValueError inside a traced function.
The application catches the re-raised exception, so successful completion of
the script is expected.

Verify that the trace contains:
    event=function_error
    error_type=ValueError
    error_message
    traceback
    duration_ms
